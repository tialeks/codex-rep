# Обязательные правила системы

- Базовая геометрия строится на сетке 4 px. Произвольные отступы допустимы только внутри SVG.
- Высоты интерактивных элементов: 32 / 40 / 48 px. Базовая высота — 40 px.
- Радиусы: 9 px для малых деталей, 12 px для контролов, 15 px для групп, 20–24 px для поверхностей.
- Основной фон `#090909`; вложенность читается последовательностью `#111 → #171717 → #202020`, а не случайными оттенками.
- Основной текст `#f5f5f4`, вторичный `#858585`, служебный `#5f5f5f`. Светлая primary-кнопка использует `#151413` для текста.
- Компоненты используют YS Text. Начертания 400 / 500 / 700 лежат локально.
- Hover и press не меняют раскладку. Press — scale 0.97; lift — не больше 2 px.
- Переходы интерфейса используют только presets из `motion/presets.ts`.
- Каждая бесконечная и декоративная анимация обязана остановиться при `prefers-reduced-motion`.
- В лоадерах используется `brand-loader-mark.svg`, а не цветная квадратная иконка.
- Один сервис — один объект `loopframeBrand`; основной логотип, favicon и Thinking Logo всегда выбираются вместе.
- Focus-visible нельзя отключать: базовое кольцо определено токеном `--lf-focus`.
- Источник истины: `tokens.json` для инструментов и `src/styles.css` для интерфейса. `references/` служит проверкой визуальной идентичности с исходными проектами.
