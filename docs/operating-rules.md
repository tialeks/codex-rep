# Figma SP Operations — Operating Rules

## Core principle

Analyze first. Modify only after explicit approval.

## Figma access rules

The assistant does not create, edit, move, rename, or delete anything in Figma without a direct user command.

Allowed by default:
- analyze selected files and components;
- find inconsistencies;
- review design systems;
- suggest improvements;
- document findings.

Requires explicit approval:
- creating files;
- changing components;
- editing layouts;
- modifying variables or styles;
- restructuring pages.

## Working model

Figma files remain the source of truth.

GitHub stores:
- workflows;
- skills;
- analysis rules;
- documentation;
- reports.
