# Доступ к источникам

## Tracker

Предпочитай подключённый Tracker-инструмент. Если его нет, используй установленный
`stefania-tracker`, загрузив его инструкции; он отвечает за доступ, а этот скилл —
за содержательную сверку. Не хардкодь очередь, логин, окружение или путь установки.
Не копируй токены в запросы и отчёт; отсутствие подключения не обходи самодельным
поиском секретов. Скилл не требует конкретной реализации Tracker API.

Читай описание, acceptance criteria, значимые чеклисты, полную цепочку комментариев
и относящиеся к дизайну приложения. Вложения перечислить недостаточно: содержимое,
на которое опирается вывод, нужно прочитать. Непрочитанное приложение отметь явно.
Проверяй полноту страниц и последнюю доступную правку. Сохраняй ссылки на конкретные
комментарии, если инструмент их возвращает; иначе используй URL задачи с ID и датой
комментария. Не конструируй несуществующий якорь.

Явное принятое решение может заменить старый текст. Не считай молчание согласием,
вопрос требованием, а более позднюю реплику автоматическим утверждением.
При конфликте покажи источники и предложи решить конкретный вопрос. Не требуй
формальной роли согласующего, если статус решения однозначен из обсуждения.

## Figma

Используй официальный Figma MCP и доступные операции чтения: структуру, screenshot,
свойства и настройки. Сначала определяй конкретные nodes/версию, затем углубляйся.
Для JS-чтения через `use_figma` предварительно загрузи установленный `figma-use`;
исполняй только чтение. Для `get_design_context` предварительно загрузи
`figma-design-to-code`, если он требуется инструментом/окружением; получение
контекста здесь не является поручением реализовать экран. Для Figma Spec загрузи
`figma-spec`. Соблюдай актуальные инструкции доступных инструментов, не полагайся
на фиксированные названия аргументов из этого файла.

Если значимые аннотации/комментарии или Prototype недоступны через текущие
инструменты, перечисли ограничение. Не выдавай результат поиска только по дереву
слоёв за чтение всех пояснений. Не утверждай, что у экрана нет настроек/связей,
если их не удалось прочитать.

Для визуальных выводов нужны просмотренные изображения целевых экранов. Дерево
узлов и сгенерированный код не доказывают качество композиции. Не меняй исходник
ради скриншота; выбирай доступный способ чтения/экспорта. Если можно получить только
миниатюру, мелкие тексты и отступы остаются непроверенными.

Обратное также верно: изображение не доказывает целостность instances и bindings.
Для этой части прочитай структуру и свойства по library-usage.md, включая вложенные
и скрытые элементы в согласованном объёме. Отсутствие property в ответе инструмента
не равно отсутствию binding в Figma. Если доступен только частичный ответ, дочитай
или зафиксируй ограничение. Библиотеку читай лишь в объёме эталонов и правил,
необходимых для проверки текущего макета.

Если файл содержит несколько альтернатив без явного выбора, не оценивай их как
один реализуемый путь. Сопоставь версии и запроси выбор, продолжая общую часть.

## Частичный режим

Пользовательские выдержки, экспорты и скриншоты допустимы, но вывод относится
только к ним. Не называй их текущим состоянием Tracker/Figma и не утверждай,
что прочитаны неприсланные комментарии или скрытые экраны.

Полный переданный снимок может дать полное ревью в границах снимка, если включает
сами читаемые изображения, структурные данные и все применимые исходные решения.
Чужое утверждение «скриншоты проверены» без самих изображений не заменяет визуальный
просмотр. Только PNG без свойств не позволяет полностью проверить компоненты и
variables. Полнота снимка не доказывает актуальность живого файла.

Пропавшие глифы, шрифты или изображения в экспорте описывай как наблюдаемый дефект
этого изображения. Без проверки исходника не приписывай причину самому макету.

При ошибке доступа продолжай независимую часть. Укажи конкретно, чего не хватает:
ссылки на целевой frame, чтения нужного тикета, оставшихся комментариев, полного
экспорта экрана или решения о версии. Проси минимальный недостающий материал.
Не подменяй недоступный источник другими чатами или похожим старым макетом.
