# Доступ к записи в Figma

Доступ появился не из этого репозитория и не из MD-файла.

Пользователь подключил Figma к ChatGPT Work как плагин/MCP-интеграцию и авторизовал её в своём аккаунте. После подключения среда предоставила инструменты Figma с разрешениями текущего пользователя.

## Как выполняется запись

1. Пользователь передаёт ссылку на Figma-файл и конкретный узел.
2. Из ссылки извлекаются:
   - `fileKey` файла;
   - `nodeId` выбранного узла.
3. Перед операцией загружаются инструкции навыка `figma-use`.
4. Инструмент `use_figma` выполняет JavaScript через Figma Plugin API внутри указанного файла.
5. Сначала узел и его свойства считываются и проверяются.
6. Затем изменяется только запрошенное свойство.
7. Инструмент возвращает идентификаторы изменённых узлов и новое значение для проверки результата.

## Пример выполненной операции

Для инстанса `11606:130837` в файле `Yr8Cw6GqsShWUC94tqXTVY` было найдено булево component property:

```text
Center Picture#3143:11
```

Оно было включено через метод экземпляра:

```javascript
instance.setProperties({
  "Center Picture#3143:11": true
});
```

После операции значение повторно проверено: `false → true`.

## Важные ограничения

- MD-скиллы сами по себе не дают доступ к Figma.
- Репозиторий не хранит Figma-токены или учётные данные.
- Запись возможна только пока Figma-интеграция подключена и у авторизованного пользователя есть права на файл.
- Изменения в Figma выполняются только по явной команде пользователя.
- Секреты, токены и данные авторизации в этот скилл не записываются.
