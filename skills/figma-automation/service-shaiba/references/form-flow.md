# Анкета и получение ответа

В среде с visualize прочитать её инструкции, скопировать готовый HTML-фрагмент из assets/questionnaire.html в допустимый путь вывода и показать нативной inline-ссылкой. Не ссылаться на HTML как на уже подключённую генерацию.

В другом клиенте открыть/предоставить assets/questionnaire-standalone.html. Если HTML недоступен, показать один полный текстовый опрос:
1. General color: Solid + HEX или Gradient + 2–6 HEX по порядку и направление.
2. Логотип: использовать уже приложенный / приложить новый.
3. Удалить фон: да / нет.
4. Размещение: S / M / L / full surface / На грани.
Геометрия и свет закреплены. Попросить подтвердить полный набор ответов.

Кнопка HTML отправляет подтверждённые параметры как следующее сообщение в чат через поддерживаемый интерфейс `window.openai.sendFollowUpMessage`. В этом чате сразу начать генерацию по ним, если логотип уже доступен. Вложение нельзя передать из inline-формы: попросить приложить логотип обычным сообщением, если его нет. Не требовать JSON или повторной анкеты. В клиенте без этого интерфейса форма показывает готовый текст запроса для ручной отправки; не обещать автоматическую генерацию в таком клиенте.

Если логотип уже доступен в чате, принять его без повторной загрузки. Поле загрузки из формы убрано, так как оно не передавало файл ассистенту. Если логотипа нет, всё равно сначала показать анкету; после ответа получить исходник до генерации. Не пропускать анкету из-за наличия файла или полностью описанных параметров.
