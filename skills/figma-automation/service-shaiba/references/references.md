# Визуальные эталоны

Эталон геометрии обновлён по присланному пользователем изображению 950×950. `full-surface-correct.png` — новый пользовательский эталон 1254×1254 для полного покрытия лица. Остальные PNG сохранены из Figma, 40×40. Не считать их точными измерительными чертежами. Не требовать Figma-доступ при обычной работе. Использовать geometry + lighting + один нужный вариант, не загружать все изображения каждый раз.
