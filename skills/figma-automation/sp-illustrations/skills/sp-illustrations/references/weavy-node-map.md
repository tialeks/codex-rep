Проверено по доступной версии флоу `6pKHdMbJuTDpV9ZwODxqVP` 27 сентября 2026 года. Разделяй видимые соединения и расширения плагина.

| Узел | Связь |
| --- | --- |
| File 1 | Исходник предмета → `Any LLM` как Image 1 и напрямую в оба генератора как Image 1. |
| File 2–4 | Три постоянных стилевых эталона → `Any LLM` как Images 2–4. Прямых связей с генераторами нет. |

## Согласованное расширение плагина — 28 сентября 2026

Дизайнер подтвердил: «Да, закрепить прямые стилевые входы». Три постоянных File 2–4 теперь идут также прямо в генератор. Остальные роли сохраняются: содержание → анализ эталонов → предметный промпт → генерация → проверка → прозрачная копия.

- По тексту: промпт + три изображения STYLE. Ни одно из них не является источником предмета.
- По исходнику: промпт + Image 1 CONTENT + Images 2–4 STYLE.
- При стилевой коррекции: исходник содержания при наличии, три STYLE и исправляемый кандидат; роли перечисляются явно.
- При локальной правке фона, alpha, знака или детали: выбранный удачный файл без повторного стилевого переноса; BRAND добавляется только при необходимости. Сохранение материала проверяется по material-regression.md.
- При извлечении прозрачной копии: только выбранный результат как редактируемое изображение, без повторного переноса стиля.

Это осознанное изменение одного подключения по сравнению с исходным графом выше. Генератор ChatGPT не является парой Gemini и не гарантирует побайтового повторения Weavy. Один основной кандидат достаточен; альтернативы по запросу. Узкая материальная калибровка еды остаётся частью общего анализа, 12 оригиналов — дополнительный контекст, а не 12 новых прямых стилевых входов.

Проверка на новом походном сюжете: прямая передача эталонов дала визуально более цельные объёмы и мягкую подачу, чем текстовые пробы. Это наблюдение по одному сюжету без фиксированного seed; оно не является подтверждением качества всех будущих иллюстраций. Внешняя тень и точный фон в этой пробе ещё не исправлены.

## Уточнение по аудиту семи сцен

Для нового автомобиля или сцены с игровыми контроллерами допустим один CATEGORY по audit-calibration.md в дополнение к трём STYLE. Короткий предметный промпт и этот вход проверены совместно, вклад каждого отдельно не установлен. CATEGORY сохраняется при стилевой коррекции, но не участвует в локальной правке/alpha. Для еды автоматическое добавление CATEGORY не показало улучшения и не закреплено. Состав сложной сцены фиксируется коротким списком до генерации и проверяется после. Все стадии и ограничения экспорта остаются общими.
