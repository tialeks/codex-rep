# Facet

Студия 3D-графики для Codex. В комплекте плагин, 284 визуальных пресета и 36 материалов. Личной истории и заданий автора в пакете нет.

## Установка

1. Распакуйте `Facet` в постоянную папку. Нужны Codex desktop со встроенной генерацией изображений и Python 3.9+; локальный сервер рассчитан на macOS/Linux.
2. Из этой папки выполните:

   ```sh
   codex plugin marketplace add .
   codex plugin add reference-style-3d@facet-team
   ```

   Или откройте папку в Codex и попросите: **«Установи Facet из локального каталога и подготовь зависимости из requirements.txt»**. Не удаляйте папку после регистрации: это источник будущих переустановок.
3. Начните новый чат, выберите плагин Facet и напишите **«Открой студию Facet»**. Пресеты появятся автоматически.

Название `facet-team` должно быть свободно либо уже указывать на эту папку; не заменяйте другой каталог с таким именем. Личный список установленных плагинов сохраняется.

## Первый результат

Выберите пресет → напишите свою тему → нажмите **Создать**. Параметры можно менять. Результат появится в чате и **Истории**. Если агент отключён, в чате Codex напишите **«Подключись к очереди студии»**.

API-ключ для обычной работы не нужен. Генерация расходует доступные лимиты Codex. Результаты вариативны; встроенный imagegen не гарантирует фиксированное разрешение или 4K.
