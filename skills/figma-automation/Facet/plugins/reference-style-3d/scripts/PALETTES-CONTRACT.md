# Личные палитры · контракт CLI

`python3 scripts/palettes.py` — автономный CLI на стандартной библиотеке Python 3.9+, macOS/Linux (использует advisory `flock`). Не требует сервера, ключа, сети или активного чата.

Постоянное хранилище: `~/.local/share/reference-style-3d/palettes.json`. Для теста/переноса каталога: переменная `REFERENCE_STYLE_3D_DATA_DIR`. Хранилище находится вне версионированного плагина и переживает обновления и новые чаты. Между компьютерами данные автоматически не синхронизируются.

Команды:

```sh
python3 scripts/palettes.py list
python3 scripts/palettes.py add --name 'Тёплая' --colors '#F25D45' '#FFF5E7'
python3 scripts/palettes.py add --name 'Тёплая' --colors '#F35D45' --replace
python3 scripts/palettes.py remove --id ID
python3 scripts/palettes.py export --output my-palettes.json
python3 scripts/palettes.py import --file my-palettes.json
```

Успех: exit 0, JSON stdout с `ok:true`, `command`, `changed`, путём `store` и подтверждёнными чтением `schemaVersion:1,palettes`. Ошибка данных/файла: exit 1, JSON stdout `ok:false,error`. Ошибки синтаксиса аргументов обрабатывает argparse (exit 2). `changed` относится к личному хранилищу, а не созданию файла экспорта.

Формат файла: `{"schemaVersion":1,"palettes":[{"id":"...","name":"...","colors":["#AABBCC"]}]}`. Никаких абсолютных путей или состояния чата в переносимом экспорте. Название после удаления крайних пробелов 1–60 символов; 1–8 HEX6 цветов, допускается ввод без # и в нижнем регистре, хранится #RRGGBB. Не более 128 палитр. Имена сравниваются без учёта регистра. Повтор имени с теми же цветами идемпотентен; другие цвета требуют явного `--replace`. Замена сохраняет прежние id и имя. Импорт сливается с существующими палитрами, не стирает отсутствующие в импортируемом файле. Конфликт id между разными именами — ошибка.

Запись: валидация всего входа и результата до изменений; блокировка `palettes.lock` на весь read–modify–write–readback; временный файл в том же каталоге, fsync, atomic replace, fsync каталога. Повреждённые/нечитаемые существующие файлы не заменяются. Экспорт также не перезаписывает повреждённый файл. Блокировка advisory: все писатели используют тот же `locked_store`; локальный сервер вызывает функции этого модуля. Удаление неизвестного id — успешная операция без изменения.

Боковая форма сохраняет палитру через локальный `/library` без вызова модели. Для операции из чата агент вызывает CLI. Успех подтверждается `ok:true` после readback; widgetState не заменяет библиотеку. При открытии renderer читает актуальный список. CLI не устанавливает плагин.

Проверка: `python3 -m unittest discover -s scripts -p test_palettes.py -v` из каталога пакета.

Чтение (`list`, источник `export`) не создаёт каталоги и lock-файлы. Atomic replace писателя даёт целый старый или новый снимок. Readback и эксклюзивная блокировка сохраняются для изменений; экспорт записывает только указанный файл.
