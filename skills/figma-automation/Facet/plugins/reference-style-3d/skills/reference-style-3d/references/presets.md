# Визуальная библиотека пресетов

Пресет — сохранённый снимок параметров с превью проверенного по происхождению PNG. Это не автоматическое одобрение художественного качества. Превью помогает выбрать оформление; оно не обещает повторение конкретных предметов или геометрии и само не становится входным референсом генерации.

В библиотеку принимаются только генерации без выбранных свойств референса. Такой результат нельзя преобразовать в самостоятельный пресет удалением `reference`: это потеря части условий генерации. Импорт отклоняет его с объяснением.

## Применение

Применяй весь снимок параметров от стабильных значений по умолчанию. Сохраняй текущие `topic`, `subjects`, `avoid`; очищай `reference`, включая свойства и привязку изображения. Иначе выбранные свойства референса могут переопределить оформление пресета. Покажи подтверждение применения и отключения референса; пользователь может выбрать его заново.

Изменение пресета не запускает генерацию. Новый запрос возникает только после «Создать». Источник уже отправленного задания — его неизменяемый снимок, а не выбранная позднее карточка или состояние формы. Допустимость сочетания определяет штатный компилятор; несовместимые параметры не исправляются молча.

## Хранение и показ

Встроенная коллекция находится в `assets/presets/`: каталог настроек и WEBP-превью. `ensure_bundled_library` при запуске студии или renderer проверяет пакет и добавляет отсутствующие записи во внешнюю библиотеку. Ручной импорт не нужен. Существующие избранное и личные записи сохраняются; конфликт одинаковых ID не перезаписывается. Проверка коллекции не выполняется при каждом опросе очереди.

`scripts/presets.py` обслуживает `presets.json`, `previews/` и избранное во внешнем каталоге `REFERENCE_STYLE_3D_DATA_DIR` (по умолчанию `~/.local/share/reference-style-3d`). В пакет плагина пользовательские картинки и записи не входят. Идентификатор записи стабилен и не зависит от позиции карточки. `source: collection` означает готовую коллекцию, `source: personal` — сохранённую генерацию пользователя; это не рейтинг качества.

Боковая студия показывает 12 карточек на странице, четыре колонки на обычной ширине, без ограничения общей высоты. Метаданные библиотеки доступны локально; изображения подгружаются отдельно. Поиск, фильтры и страницы работают без запроса в чат. Избранное сохраняется через `/library`.

Хранимые превью имеют размер до 1024 px. Миниатюры для чата адаптируются под общий лимит 1 MB; увеличение миниатюры не равно качеству исходного PNG. Исходные PNG и настройки не меняются. Если библиотека не помещается, renderer явно сообщает ошибку, не пропускает карточки.

## История и сохранение

История хранит каждую фактическую попытку с исходным PNG, снимком и проверяемым исполнением, включая `fail` и `limited`. Кнопка «Повторить настройки» вызывает `/repeat-history`: восстанавливает весь исходный снимок, включая тему и проверенный референс, без запуска генерации. Архивная картинка не становится новым референсом.

Кнопка «Сохранить пресет» вызывает `/library` с `action: save_history_preset` и ID результата. Сервер проверяет архив и сохраняет параметры именно этой попытки. Пользователь может сохранить и результат с замечаниями; это не меняет его review. Генерация с выбранными свойствами референса остаётся недопустимой для самостоятельного пресета.

## Операции из чата

Только для встроенной формы в чате используется следующий transport. Форма отправляет сообщение `reference-style-3d: библиотека пресетов.` и JSON:

```json
{"schemaVersion":1,"operation":{"action":"set_favorite","id":"stable-id","favorite":true,"page":2,"filters":{"scope":"all","type":"icon"}},"settings":{}}
```

`settings` содержит текущий полный снимок для возврата формы. Сохрани его в файл для `--settings`, а `operation.filters` — отдельным JSON для `--preset-filters`. Передай `operation.page` в `--preset-page`: нумерация начинается с 1. Если эти поля отсутствуют, используй страницу 1 без фильтров. Не сбрасывай тему и ручные настройки при навигации или сохранении избранного.

Общий возврат формы:

```sh
python3 <plugin>/scripts/render_controls.py \
  --output /absolute/controls.html --view presets \
  --settings /absolute/request.json \
  --preset-page 2 --preset-filters /absolute/filters.json
```

Число страницы и файлы берутся из полученной операции. Если после удаления из избранного страница опустела, библиотека возвращает ближайшую допустимую страницу.

При возврате после операции библиотеки сохраняй явно выбранный в этом снимке референс: если `settings.reference.image` содержит path/name/sha256, проверь существование файла и совпадение SHA-256, затем передай renderer `--reference` и `--reference-name` вместе с `--settings`. Изображение из истории или превью пресета вместо него не подставляй. Если файл недоступен или изменён, сохрани выбранные свойства и сообщи, что изображение нужно прикрепить повторно. Само применение другого пресета по-прежнему очищает референс.

- `set_favorite`: выполнить `python3 <plugin>/scripts/presets.py favorite --id <id> --on --page <page> --filters /absolute/filters.json` или `--off`, затем вернуть форму на текущую страницу с теми же фильтрами и `settings`. Сердце подтверждается только после успешной записи и чтения библиотеки.
- `load_preset_library`: вызвать renderer с запрошенными `operation.page`, `operation.filters`, переданными `settings` и `--view presets`. Поиск начинается со страницы 1; навигация запрашивает конкретную страницу. Само чтение ничего не записывает.
- `save_generation_preset`: сначала найти точно выбранный фактический PNG и соответствующее исполнение с исходным снимком, receipt и доверенным manifest pin. Текущий `settings` формы не заменяет параметры той генерации. При неоднозначности запросить выбор результата; если картинки нет, запросить вложение. Без проверяемого исполнения не создавать запись с выдуманными параметрами.

Сохранение собственной генерации:

```sh
python3 <plugin>/scripts/presets.py import-execution \
  --execution /absolute/execution \
  --file /absolute/result.png \
  --expected-manifest-sha256 <trusted-pin> \
  --name "Название пресета"
```

Команда проверяет связь PNG, receipt, аргументов и исходного снимка. Только успешная запись с readback означает сохранение. После неё верни форму с `--view presets`, исходными `settings`, страницей и фильтрами операции; сам отправленный запрос ещё не подтверждает запись. Если новый пресет не подходит под текущие фильтры, сообщи об этом, не меняя их молча.

## Импорт коллекции

Внешний manifest имеет ровно поля `schemaVersion:1` и `presets`. Каждая строка содержит `id`, `name`, `settings`, `file` (абсолютный путь к действительному PNG), `source:"collection"`.

```sh
python3 <plugin>/scripts/presets.py import-manifest --file /absolute/seed.json
```

Импорт валидирует актуальные controls и сохраняет их без `topic`, `subjects`, `avoid`, `reference`. Сюжет, промпт сцен, отчёт проверки и порядковый номер результата в пользовательскую запись не переносятся. Формат снимка настроек и формат библиотеки версионируются независимо; несовместимые версии не мигрируют неявно.
