# Постоянная библиотека палитр

Запускай `python3 <plugin-root>/scripts/palettes.py` с нужной командой. Корень — два уровня выше каталога SKILL.md. Хранилище по умолчанию: `~/.local/share/reference-style-3d/palettes.json`; оно общее для чатов на этом компьютере и переживает обновления плагина. `REFERENCE_STYLE_3D_DATA_DIR` переопределяет каталог для тестов/переносного окружения. Это локальная библиотека пользователя, не облачная синхронизация.

- `list` — прочитать подтверждённые палитры; при обычном открытии формы это делает renderer.
- `add --name <name> --colors '#RRGGBB' '#RRGGBB'` — сохранить именованную палитру. Передавай аргументы безопасно, без shell interpolation пользовательского текста. Повтор одинаковых имени и цветов идемпотентен. Замена существующей другой палитры — только по просьбе заменить, с `--replace`.
- `remove --id <id>` — только по просьбе удалить указанную палитру.
- `export --output <path>` — переносимый JSON для другого дизайнера.
- `import --file <path>` — проверить файл и импортировать; конфликт не разрешать скрытой заменой.

Новая палитра: понятное имя, от 1 до 8 цветов HEX. Нельзя молча сохранять образцы из widgetState: это текущий выбор, а не постоянная библиотека. Не придумывай имя вместо отсутствующего при запросе сохранения — попроси его.

Успех подтверждается `ok:true` от CLI после встроенного readback. Только затем говори «Палитра сохранена в библиотеке плагина» и обновляй форму. При ошибке сохрани текущие цвета в ответе, объясни ошибку и не ставь состояние успеха. Повреждённую библиотеку нельзя затирать пустой. Встроенные палитры формы остаются частью пакета; пользовательская библиотека переносится явно export/import и не публикуется автоматически.

В боковой студии сохранение выполняется через локальный `/library`, с теми же блокировкой, валидацией и readback; вызов агента не нужен. Операция не запускает генерацию и не сбрасывает параметры.

Для библиотечного запроса из чата верни снимок через renderer `--settings`. При наличии `reference.image` сверь путь и SHA и передай ту же картинку через `--reference`. Недоступное или изменённое вложение запроси повторно, не заменяй скрыто.
