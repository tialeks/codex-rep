# Facet · 3D-графика

Независимый плагин со встроенным imagegen. Корень пакета — два уровня выше каталога этого файла. Боковая студия использует локальную очередь; готовый бриф из чата можно выполнить напрямую.

## Команды открытия

- Считать «плагин Саши» и «плагин с генерацией» именами Facet. Распознавать склонения и смысловые варианты: открыть, запустить, показать; сгенерировать иллюстрацию, картинку или 3D-графику в плагине Саши.
- По этим командам в браузерном чате сразу показывать встроенную форму через `render_controls.py` и официальный visualize skill, без уточнения названия плагина и без запуска локальной очереди. Выводить форму в текущем ответе.
- Запрос генерации через плагин без подтверждённого снимка сначала открывает форму; текст темы использовать как предложение для заполнения. Подтверждённый снимок выполнять без повторной формы.
- В Codex desktop сохранять боковую студию по умолчанию; явно выбранный встроенный интерфейс имеет приоритет.

## Выбери действие

- Упоминание плагина или запрос параметров: [покажи форму](references/chat-controls.md). Документы генерации для этого не нужны.
- Запрос «добавь референс к снимку параметров»: сохрани settings, получи явно выбранное вложение и верни [форму с этим снимком и картинкой](references/chat-controls.md). Это настройка, не запуск генерации.
- Сообщение `reference-style-3d: библиотека пресетов` или сохранение удачной генерации: выполни операцию по [presets.md](references/presets.md), затем верни форму с подтверждённой библиотекой и переданными настройками. Это не запуск генерации.
- Операция с библиотекой палитр: выполни её по [palettes.md](references/palettes.md).
- Готовый бриф или снимок: переходи к генерации без повторной анкеты.

## Генерация

1. Прочитай официальный imagegen skill, [правила содержания](references/prompting.md) и [подготовку](references/generation-preparation.md), если ещё не читал в этом чате.
2. Каждый отправленный снимок — самостоятельное задание. Выполняй все; отменяй или заменяй только по явной просьбе. Сохрани исходное сообщение и `settings` без правок в отдельный запрос в каталоге задачи, вне пакета плагина. Более позднее состояние формы его не меняет. Для текстового брифа перенеси явные требования, остальное выбери по смыслу: белый фон, один предмет; сет без числа — четыре изображения. Для текстовой формы восстанови все перечисленные параметры.
3. Напиши в `prompt` только содержание сцен или адресную коррекцию. Настройки и стиль компилируются один раз. До запуска сверь состав каждого сюжета с выбранным типом графики: сюжетный бриф не должен задавать другое количество предметов или отменять параметры снимка. Оси графики описаны в [graphics-controls.md](references/graphics-controls.md); не подменяй тип графики размером PNG.
4. По умолчанию `referenceMode=prompt`. Оригиналы из [каталога](references/sources.json) добавляй через `selected` только с конкретной причиной. Подготовка сама собирает выбранные материалы в один лист. При `settings.reference.facets` используй [контракт свойств референса](references/reference-guidance.md): нужна одна точно выбранная картинка этого задания. Если её нет, сохрани снимок и запроси картинку до генерации, затем продолжи тот же запрос. Не подставляй изображение из истории.
5. Выполни prepare и verify. Просмотри реально передаваемые изображения. Передай точные аргументы verify встроенному imagegen; историю картинок и переписанные инструкции не добавляй. Сохрани фактический PNG, аргументы и receipt по инструкции подготовки.
6. Сравни PNG с релевантными оригиналами при сопоставимом размере по [визуальному контракту](references/style-contract.md). При конкретном дефекте допустима одна адресная правка: тот же снимок, исходник как EDIT SOURCE, отдельное исполнение и повторная проверка всего листа. Оставшееся ограничение покажи; скрытую серию не начинай.
7. После каждого полученного PNG заполни review с наблюдениями и сразу сохрани попытку с [проверкой доказательств](references/review-verification.md) в «Историю»: `python3 scripts/history.py --import-attempt <job.json> --execution <execution> --file <png> --review <review.json> --manifest-sha256 <pin>`. `job.json` содержит отдельный ID задания и исходный `request.settings`. Архивируй исходный PNG побайтово, без уменьшения и перекодирования; уменьшать можно только отдельное превью. Сохраняй каждую попытку независимо от `pass`, `limited` или `fail`: видимость не зависит от приёмки. Без фактического PNG запись в историю изображений не создавай. Покажи PNG и фактический статус; `complete` по-прежнему не принимает `fail`. Целостность файлов не означает художественную приёмку; новое изображение не становится эталоном без одобрения пользователя.

## Качество исходника

У встроенного imagegen нет аргументов quality/size: требование к качеству задаётся промптом, но фиксированное разрешение, 4K и максимальное качество не гарантируются. Не выдумывай аргументы инструмента. Требование к чистоте рендера включено в style.txt; сложность и детализация остаются из снимка. Сохраняй оригинальный PNG без уменьшения и перекодирования; отдельные превью не заменяют исходник.
