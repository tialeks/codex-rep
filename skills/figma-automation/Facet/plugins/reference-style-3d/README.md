# Facet — студия 3D-графики

Плагин для Codex: иконки, предметы и иллюстрации в едином визуальном стиле, 284 визуальных пресета и 36 материалов. Настраивайте композицию, цвета, материалы и приёмы или начинайте с визуального пресета.

## Установка

Нужны Codex desktop со встроенной генерацией изображений, Python 3.9+ и Pillow (`requirements.txt`). Локальная студия рассчитана на macOS/Linux; Windows не проверен. API-ключ для обычной генерации не нужен.

Распакуйте поставку `Facet` в постоянную папку. Откройте терминал в ней:

```sh
codex plugin marketplace add .
codex plugin add reference-style-3d@facet-team
```

Или откройте эту папку в Codex и попросите: **«Установи Facet из локального каталога и подготовь Python-зависимости»**. Если `codex` не найден в терминале, используйте этот способ. Личный каталог других плагинов заменять не нужно.

После установки начните новый чат, выберите плагин Facet и напишите **«Открой студию Facet»**. Агент откроет боковую панель и подключится к очереди в этом чате.

## Использование

1. В **Студии** задайте тему и параметры. Либо выберите картинку в **Пресетах**: оформление применится, свою тему можно сохранить.
2. При необходимости загрузите референс и отметьте только те свойства, которые хотите перенести.
3. Нажмите **Создать**. Каждая отправка — отдельное задание. Результаты появляются в чате и **Истории**, где можно скачать PNG, повторить настройки и сохранить пресет.

Сердце добавляет пресет в избранное. Свои палитры и наборы материалов тоже можно сохранять. Основной материал задаёт крупные поверхности, акценты — отдельные части; автоподбор выбирает привычные материалы предметов.

## Что учитывать

- Генерация вероятностная: фактуры, цвета и приёмы иногда требуют коррекции. Пресет повторяет настройки, а не конкретную картинку. Проверяйте результат перед использованием.
- Встроенный imagegen сам определяет разрешение; гарантии 4K нет. Исходный PNG сохраняется без уменьшения. Число ячеек делит разрешение всего листа между изображениями.
- Очередь обслуживает активный агент Codex. Если он отключён, напишите в чате Codex **«Подключись к очереди студии»**. Веб-страница не запускает завершённый чат автоматически.
- История, избранное и пользовательские библиотеки лежат отдельно: `~/.local/share/reference-style-3d` (или `REFERENCE_STYLE_3D_DATA_DIR`). В самом плагине нет ваших генераций. Встроенная коллекция пресетов входит в плагин и появляется автоматически; личные данные сохраняются при обновлении.
