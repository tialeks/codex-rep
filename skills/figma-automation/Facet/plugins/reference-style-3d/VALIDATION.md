# Проверки

Проверки запускаются из корня плагина. Они подтверждают конкретные свойства кода и файлов; художественный результат оценивается отдельно по фактическому PNG.

## Код и форма

```sh
python3 scripts/check.py
python3 scripts/render_controls.py --output /absolute/writable/form.html
```

`check.py` — команда для разработки и выпуска, не часть каждой генерации. Ей нужны Python с зависимостями из `requirements.txt` и Node.js. Она запускает Python, Node и аудит пакета; аудит также запрещает результаты генераций и незарегистрированные картинки внутри плагина.

Python проверяет параметры и их совместимость, привязку референса, материалы, палитры, подготовку и целостность исполнения. Node проверяет обработчики формы, восстановление фокуса, точное применение визуальных пресетов, фильтры и состояние неподтверждённого избранного. Python также проверяет постоянную библиотеку пресетов, независимость пользовательских данных от пакета и связь сохранённой генерации с её снимком. Эти проверки не заменяют просмотр формы в боковой студии Codex: перед выпуском проверить отправку, ошибки, восстановление снимка, клавиатуру, попапы и выбранный референс.

Сохраняйте фактический вывод команд с версией проверенного пакета. Результаты проверок и отчёты сохраняются вне пакета плагина.

## Генерация

Для каждого исполнения сохраняются запрос, prompt, manifest с pin, входные изображения, фактические аргументы, receipt, PNG и ручной review. [Подготовка](skills/reference-style-3d/references/generation-preparation.md) описывает привязку; [проверка PNG](skills/reference-style-3d/references/review-verification.md) — структуру review и команду проверки.

Визуально проверяются форма, материалы, свет, композиция, цвета, стилевое сходство и каждое выбранное свойство референса. Оценка записывается конкретными наблюдениями, включая ограничения и провалы. Исправленная попытка сохраняется отдельно и не доказывает попадание с первого раза.

## Ограничения

- Правильный промпт не гарантирует соблюдения основы, акцентов, ракурса, числа предметов или выбранного приёма. Это проверяется в изображении.
- Референс направляет выбранные свойства; точность переноса и сохранения остальных осей требует сравнения результата.
- Программная проверка подтверждает связь файлов и декодируемость PNG, но не правдивость ручных наблюдений и не принадлежность авторскому стилю.
- Сохранённый результат не становится новым эталоном автоматически. Локальная правка не гарантирует неизменность остальных пикселей.
