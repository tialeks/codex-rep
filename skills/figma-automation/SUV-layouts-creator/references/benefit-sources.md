# Источник выгоды: селектор, крутилка, уровень, Балдёж

Подтверждено пользователем и по read-only-разбору секшена [«Механики»](https://www.figma.com/design/Yr8Cw6GqsShWUC94tqXTVY/Свой-Плюсы-CJ---SPECS?node-id=29394-169800). Файл `Yr8Cw6GqsShWUC94tqXTVY`, страница `12585:190594` (SUV), секшен `29394:169800`. Это **эталон**, а не место сборки: не добавлять и не менять там макеты без новой задачи пользователя.

## Независимые параметры

Источник выгоды отвечает за то, откуда пользователь получил категорию. Он не заменяет тип Internal/External/партнёр, метод оплаты, бренд категории, размер выгоды или ограничения. Категория из крутилки, уровня или Балдежа тоже попадает на СУВ и сохраняет свои ставку, порог, крышку, методы оплаты и legal.

Не объединять одинаковые названия категорий из разных источников только потому, что совпал бренд или процент. Сохранять привязку каждого оффера к его источнику.

Последнее уточнение пользователя и скриншот имеют приоритет над ранним текстом эталона: заголовок крутилки — **«Крутилка»**, без «Попалось в крутилке». Старые формулировки остаются только вариантами распознавания входных данных.

## Что меняется в блоке выгоды

В референсе это внутренний `Benefit block → List-item`, под плашкой оплаты `Accent Bar`:

| Источник | Заголовок строки выгоды | Ведущая иконка |
|---|---|---|
| Селектор | «Категория месяца» по действующему правилу | `SUV icn / Selected`, сердечко |
| Крутилка | **«Крутилка»** | `SUV icn / Wheel`, фиолетовый барабан |
| За уровень | **«Золотой уровень»** в подтверждённом примере | `SUV icn / SP Gold`, золотой значок Плюса |
| Балдёж | **«Балдеж»**, именно так написано в эталоне | `SUV icn / balldezh`, фиолетовый ёж |

Менять именно заголовок выгоды и иконку механики. Название/описание категории в верхней части шторки и её брендовую логошайбу этим правилом не заменять. Для компактной ячейки списка сохранять категорийное имя и действующие правила ячейки; данный референс подтверждает внутреннюю строку выгоды шторки, не новый заголовок всей категории.

Источник механики имеет приоритет над Selected-сердечком обычной категории, в том числе над старым правилом Selected для Такси: для селектора остаётся Selected; для крутилки/уровня/Балдежа ставится соответствующая механика. Иконка карты в Accent Bar и верхняя брендовая шайба выполняют другие роли.

## Распознавание источника по таблицам и скриншотам

Определять источник **сразу по смыслу**, включая производные, падежи, регистр, опечатки и близкие формулировки. Искать в явном поле источника/механики, заголовке таблицы или блока, формулировке получения категории и связанных примечаниях. Для сопоставления нормализовать пробелы, регистр, ё/е и невидимые символы, но исходные пользовательские условия не переписывать из-за этой нормализации.

- **Крутилка:** «крутилка», «из крутилки», «за крутилку», «попалась в крутилке», «попалось в крутилке», «выпала в крутилке», «барабан», «вращение барабана» и смысловые производные механики → `wheel`.
- **За уровень:** «за уровень», «от уровня», «награда за уровень», «золотой уровень», «получена за достижение уровня» и смысловые производные уровня как источника выгоды → `level`.
- **Балдёж:** «Балдёж», «Балдеж», «из Балдежа», «за Балдёж», `baldezh`, `balldezh` и производные → `balldezh`.
- **Селектор:** «селектор», «выбрана в селекторе», «выбранная категория», «категория месяца» и формулировки самостоятельного выбора категории → `selector`.

Не требовать точного совпадения с dropdown. Это семантическая классификация источника, а не переименование самой категории. Обычные слова «выпала» или «уровень» вне контекста получения выгоды недостаточны. Если данные однозначны, не переспрашивать только из-за другой формулировки. При реальном противоречии нескольких источников уточнить привязку. Явное поле источника в строке имеет приоритет над общим источником блока только при отсутствии противоречия; конфликт не скрывать.

Для неизвестного конкретного уровня можно определить класс `level`, но нельзя молча назвать серебряный или иной уровень золотым. В этом случае сохранить конкретику и запросить/найти подтверждённые заголовок и вариант иконки. Подтверждённый текущий визуальный пример — золотой.

Если источник вообще не указан и контекст не противоречит селектору, форма начинает с селектора. Не превращать отсутствующий источник в основание потерять явно указанный источник из таблицы или скриншота.

## Форма ввода

### Ручная ветка

В каждой категории поле **«Источник выгоды»** с четырьмя вариантами: Селектор (по умолчанию), Крутилка, За уровень, Балдёж. Источник передаётся с категорией, сохраняется при переходах и независимом дублировании. В итоговые условия включать источник и соответствующий подтверждённый заголовок блока выгоды.

### Таблицы и скриншоты

Вместо одной общей ссылки — добавляемые блоки источников:
- первый по умолчанию Селектор;
- тип можно изменить; любой блок, включая первый, можно удалить;
- **«Добавить источник»** создаёт ещё один самостоятельный блок;
- у каждого блока своя **«Ссылка на таблицу (через Стефанию)»**;
- у каждого блока своё поле скриншотов с **multiple**: можно выбрать сразу несколько файлов и вставлять несколько скриншотов в один блок;
- изображения не смешиваются между источниками; удаление блока очищает только его предпросмотры;
- допускаются несколько блоков одного типа, если материалы пришли несколькими ссылками;
- в запрос передавать все источники с их ссылками и указанием привязки скриншотов, сохраняя порядок.

Действующее ограничение встроенного чата сохраняется: картинки внутри формы — локальный предпросмотр, не вложение для модели. Для анализа пользователь также прикрепляет изображения к сообщению, обозначая источник. Не писать, что изображения уже прочитаны или переданы через форму. Эта граница, проверка file chooser и способы ввода описаны в [intake-flow.md](intake-flow.md#ветка-таблицы).
