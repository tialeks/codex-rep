## Как сопоставлять вариант с категорией

1. Сначала проверить исключения в SKILL.md. Для Такси использовать встроенную кастомную шайбу; выбор логотипа из общего набора для её генерации не нужен.
2. Если для текущей задачи нет подходящего исходного изображения, **обязательно проверить компоненты SP UI**. Начать с набора по типу категории и при отсутствии точного совпадения проверить остальные указанные наборы: `Merchants`, `Yandex Services`, `Categories` и другие ранее указанные пользователем наборы SP UI, относящиеся к этой категории.
3. Сопоставить название категории со значением основного свойства варианта:
   - `Categories`: `Категория`;
   - `Merchants`: `merchant` (`Letter` — алфавитная группировка, не название бренда);
   - `Yandex Services`: `Service` (`Letter` также служит группировке).
4. Полное совпадение названия имеет приоритет. Если его нет, разрешено смысловое совпадение, включая русское/латинское название и очевидное обозначение того же бренда/категории.
5. Для поиска можно нормализовать регистр, лишние пробелы и невидимые форматирующие символы. Для операций Figma использовать исходное полное значение варианта или точный component key: не записывать нормализованное значение обратно вместо фактического.
6. Проверить выбранный знак визуально. Не принимать общее совпадение подстроки за тождество бренда или подбренда.
7. При нескольких правдоподобных вариантах сверить их с материалами задачи. Подходящим считать только однозначно подтверждённый вариант для этой категории.
8. Если после проверки в SP UI подходящий исходник не найден, **пропустить генерацию и поставить нейтральный серый плейсхолдер в существующий слот изображения `Center Picture`**. Сохранить размеры и структуру слота. Продолжить сборку шторки и сообщить, у каких категорий стоит плейсхолдер.

Проверенные примеры:
- «Авиабилеты» → `Categories`, вариант `Категория=Авиабилеты`, узел `2469:14688`, key `dc7eddea0e88db5b7367134b04595da4fcf5c420`.
- «ADAMAS» → `Merchants`, `merchant=adamas`, узел `4588:82128`, key `840d8743905d16b51bf8a523381df60fe9775f9e`.
- В `Yandex Services` одновременно существуют `Service=taxi-yandex` и `Service=ultima-taxi-yandex`. Простое вхождение «taxi-yandex» возвращает оба: это разные варианты. Для верхней шайбы Такси всё равно действует готовое исключение.

Читаемые названия примеров выше приведены без невидимых префиксов; при реальной сборке брать полные актуальные значения из Figma.

## Ведущая иконка ячейки

Если для ячейки нет подходящей плоской иконки, обязательно выполнить тот же поиск по указанным наборам SP UI. Найденный вариант использовать в `Cell Leading`. Если после проверки подходящего варианта нет, поместить нейтральный серый плейсхолдер в существующий слот ведущей иконки с сохранением размеров, структуры и связей инстанса. Продолжить сборку и отметить плейсхолдер в результате. Для ячейки и шторки проверять наличие подходящего изображения отдельно.

## Логотип → 3D-шайба → шторка

- Взять точный логотип выбранного варианта из указанного набора и получить его изображение/экспорт как вход генерации.
- Для категории без исключения преобразовать логотип в **трёхмерную логошайбу** через встроенный пакет `embedded/service-shaiba/`: соблюдать его геометрию, свет, сохранность бренда и размещение.
- Эти наборы пользователь явно разрешил как источник логотипов. Экспорт подходящего варианта из SP UI считается исходником текущей задачи для встроенного генератора в сценарии СУВ. Дополнительное вложение от пользователя для такого экспорта не требуется.
- Не подменять результат плоской библиотечной иконкой в месте верхней 3D-шайбы.
- Итог — на настоящем прозрачном внешнем фоне, если пользователь явно не задал иной. Проверить изображение и поставить в `Center Picture` шторки с сохранением пропорций и размеров шаблона.
- Отдельно настроить цвет свечения по акцентному брендовому цвету; чёрную подложку не включать в усреднение акцента. Это не разрешение удалять чёрные части самого логотипа.
- Источник логотипа, описание категории и условия выгоды — разные данные. Название варианта помогает найти знак, но не заменяет сохранённые формулировки и продуктовую таблицу.
