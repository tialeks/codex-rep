# СУВ — единый рабочий процесс

Пакет содержит все три модуля и их ресурсы локально. Читать модули относительно этого файла; установленная копия не требует загрузки инструкций с GitHub.

## Обязательный порядок — пропускать нельзя

1. Открыть [Tables for Agent](modules/tables-for-agent/SKILL.md). Получить и проверить нормализованные условия с ID и методами.
2. Открыть [редактуру СУВ](modules/suv-texts-1/SKILL.md) и полностью прочитать [редакторский промт](modules/suv-texts-1/references/editorial-prompt.md). Подготовить и проверить RU-тексты по блокам. Состояния задания до и после получения проверить отдельно.
3. Для EN прочитать [правила перевода и глоссарий](modules/suv-texts-1/references/translation-prompt.md), перевести проверенный RU и выполнить проверки. При RU-only этап неприменим.
4. Открыть [SUV Layouts Creator](modules/figma-automation/SUV-layouts-creator/SKILL.md) и собрать макеты из проверенных текстов.
5. После драфта и перед сдачей полностью выполнить [критическую проверку макетов](modules/figma-automation/SUV-layouts-creator/references/post-draft-review.md). Шайбы отдельно проходят [критическую приёмку](modules/figma-automation/SUV-layouts-creator/embedded/service-shaiba/references/final-review.md). Изменённую при вёрстке формулировку вернуть на этапы 2–3. При известной ошибке или непроверенном применимом обязательном пункте не объявлять результат готовым; назвать оставшиеся ограничения.

Этап редактуры обязателен для текста из таблицы, ручной формы и готового инстанса. До завершения применимых проверок не считать макет готовым. Порядок выше имеет приоритет над историческими примерами вложенных модулей.
## Правила применения

- Для поручения только по таблице выполнить нормализацию, проверку и публикацию в указанный тикет. Для поручения только по текстам выполнить редактуру/перевод. Создание макетов выполнять по запросу.
- Перед любым созданием макетов пройти все применимые этапы последовательности. Уже проверенные данные можно использовать, если они не изменились и доступны результаты проверок.
- Условия из таблицы имеют приоритет как факты. Для названий сервисов Яндекса (Internal) и формулировок использовать редакторский справочник. Написание «Баллдёж» приоритетно.
- Ресурсы `service-descriptions.pdf` и справочник описаний включены в редакторский модуль. Исторические Figma-ссылки в PDF служат происхождением примеров. Не подставлять из примечаний коммерческие условия в новый оффер.
- Ограничение длины EN и строгий глоссарий действуют по правилам перевода. Если они одновременно невыполнимы, показать точный конфликт и не выдавать затронутый текст за прошедший проверку.
